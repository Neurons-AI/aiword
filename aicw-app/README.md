# AI Word — AICoworker AI App

This folder is a mirror of the installed AI App (`skills/ai-word`), kept next to the engine it runs.
The engine (`apps/wordcraft-web`, the crates) builds to `assets/wordcraft/` with `scripts/engine.mjs build` — that
build is not committed here. Update this mirror with `node scripts/engine.mjs sync-app` from the installed app.
